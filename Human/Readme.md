# Folder Structure



This Folder Contains four folders



1] PCB\_ESP32-S3  

2] Program\_Files  

3] Hardware\_Componets  

4] Antenna\_Specs  



---



\## PCB\_ESP32-S3



The PCB folder contains all the required files for the PCB which can be custom made for this specific task.



---



## Program\_Files



The program files will give you access to the ESP-IDF code that needs to be flashed in order to extract the csi data and make spectrogram



---



## Hardware\_Componets



Hardware components contains all the remaining hardware we used for this project



---



## Antenna\_Specs



Antenna\_specs will guide you on how to make the antenna
